1. Connect this page to your repo — once

GitHub Pages alone can't save a file — there's no server behind it. So this page talks straight to GitHub's free API to save the file into your repo, and then Pages serves it. Your token is only stored in your browser, never in the site files.

How to get a free token (2 minutes)
  1. On github.com, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Set it to Only select repositories and pick just this one repo.
  3. Under Repository permissions, give Contents: Read and write only. Nothing else.
  4. Copy the token, paste it above, and save. GitHub only shows it once, so keep it somewhere safe.
  5. Make the repo first, and publish Pages from it (Settings → Pages → Deploy from a branch → main → / root), or this page will say “repo not found”.
